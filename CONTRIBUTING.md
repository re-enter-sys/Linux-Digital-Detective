# Contributing

Thank you for your interest in contributing to **Linux Digital Detective**.

LDD focuses on Linux digital forensics, incident response, detection engineering, evidence analysis, attack-chain reconstruction, MITRE ATT&CK mapping, and defensive security research.

## Before You Contribute

Before opening an issue or pull request:

1. Review the README.
2. Check existing issues and pull requests.
3. Keep changes focused and relevant to the project.
4. Do not include real credentials or sensitive forensic evidence.
5. Test your changes before submitting them.
