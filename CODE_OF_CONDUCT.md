# Code of Conduct

## Our Commitment

Linux Digital Detective is a cybersecurity learning and defensive-security project.

We want the project to remain a respectful, professional, and constructive environment for contributors, researchers, students, and security practitioners of different experience levels.

## Expected Behavior

Contributors and participants are expected to:

- Be respectful and professional.
- Communicate constructively.
- Focus technical discussions on the work.
- Accept reasonable technical criticism.
- Respect different levels of knowledge and experience.
- Give credit where appropriate.
- Keep security research ethical and authorized.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or intimidation
- Personal attacks
- Discrimination or hateful conduct
- Threats or abusive behavior
- Deliberate disruption of project resources
- Publishing someone's private information without permission
- Sharing confidential information without authorization
- Using project discussions to facilitate malicious or unauthorized activity

## Security-Related Conduct

Because Linux Digital Detective is a cybersecurity project, participants must use security-related functionality responsibly.

Do not use project resources to encourage or facilitate:

- Unauthorized system access
- Credential theft
- Destructive attacks
- Malware deployment
- Privacy violations
- Attacks against systems without authorization

## Enforcement

Project maintainers may remove, edit, or reject contributions or discussions that violate this code of conduct.

Repeated or serious violations may result in removal from project participation.

## Reporting

If you experience or observe unacceptable behavior, report it privately to the project maintainer through the contact mechanism provided by the repository.

Security vulnerabilities should be reported according to the process described in `SECURITY.md`.

## Scope

This Code of Conduct applies to:

- Issues
- Pull requests
- Discussions
- Repository contributions
- Project-related communications
- Other interactions directly associated with Linux Digital Detective
